# claude-skills

Pure1979'un Claude skill seti.

- **[DURUM.md](DURUM.md)**: projenin son durumu ve 5 kurtarma noktası. Her şeye buradan başla.
- **[HARITA.md](HARITA.md)**: kurulu skill'ler ve ileride kurulabilecek aday kaynaklar.
- **[CLAUDE.md](CLAUDE.md)**: Claude'un bu repoda nasıl çalışacağına dair kurallar.
- **skills/**: kurulan skill'ler, kategorilere göre.

Dışarıdan alınan skill'ler kendi lisanslarıyla birlikte tutulur. Her birinin kaynağı, klasöründeki `KAYNAK.md` dosyasında yazar.
